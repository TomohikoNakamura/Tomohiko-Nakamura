Seismic Signal Decomposition Using Blind Source Separation

We investigate blind source separation of multicomponent seismic recordings to analyze overlapping wavefield components. Using the time-frequency and polarization structure of three-component observations, we explore how different arrivals and residual contributions can be distinguished. The diagram is conceptual and does not imply experimentally validated P/S-wave classification.
