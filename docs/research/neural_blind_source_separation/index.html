Neural Blind Source Separation

We study multichannel blind source separation using neural source models and neural inference, including empirical-Bayesian independent deeply learned matrix analysis (IDLMA), product-of-prior IDLMA (PoP-IDLMA), and independent deeply learned tensor analysis (IDLTA). This line also covers joint neural blind source separation and speaker diarization for distant multi-talker speech recognition.

Includes collaborative research on multi-talker speech recognition
